## Manual workflow

Open **Actions → Test → Run workflow**, choose branch `experiment/openai-shadow-20261029`, leave `collection_name_sha256` empty.

Choose **`mode=llm`** once on this branch. It runs offline guard tests, fetches/validates all five abstracts without a model secret, and checks current-day pricing and the cumulative budget before allowing the explicitly authorized v2 request. If evidence is incomplete, it exits before reserving v2 or calling a model. This integrated gate makes a separate `tests` run unnecessary. `mode=tests` remains an optional sources-only diagnostic mode with no OpenAI secret. A successful workflow badge alone does not mean a model request occurred: inspect `ready`, `price_ready`, `api_requests_this_run` and `run_status.json`.

The existing `OPENAI_API_KEY` Secret is supplied only to the paid test step, with fixed official endpoint/model. There are no new secrets, encrypted injection, private profiles, Zotero credentials or email credentials. The standard job GitHub token can update only the experimental ledger via the fixed test-branch path. This workflow has no schedule, push or PR trigger, and does not invoke daily delivery, main/provider migration or production budget state.
